# Exercícios da Apostila FACCAT em Java

Resoluções em Java dos exercícios da apostila FACCAT, feitas para praticar lógica de programação.

## Conteúdos praticados

- Variáveis e tipos de dados
- Entrada e saída de dados
- Operadores aritméticos e lógicos
- Estruturas condicionais
- Laços de repetição

## Como executar

1. Baixe o repositório em **Code → Download ZIP** e extraia os arquivos.
2. Abra a pasta do projeto no IntelliJ IDEA.
3. Abra a classe do exercício que deseja testar e clique em **Run** ao lado do método `main`.
